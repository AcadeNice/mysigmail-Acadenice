# Guide utilisateur – Générateur de signature

Ce guide décrit comment utiliser l'application web AcadéNice pour créer et installer votre signature e-mail.

## Prérequis

- Un navigateur moderne (Chrome, Firefox, Edge, Safari) avec JavaScript activé.
- Facultatif : un avatar carré (JPG/PNG/GIF) si vous souhaitez l'ajouter.

## Démarrer

1. **Accéder à l'application** : ouvrez l'URL fournie par votre administrateur.
2. **Déverrouiller l'interface** : renseignez votre nom, email et téléphone dans le formulaire d'accueil. Ces informations servent à pré-remplir la signature et restent stockées localement dans votre navigateur.
3. **Naviguer entre les onglets** :
   - `Base` : infos principales (nom, poste, coordonnées).
   - `Social` : liens vers vos réseaux.
   - `Options` : polices, couleurs, forme et taille de l'avatar.
   - `Add-ons` : bannière, disclaimer, CTA.
   - `Templates` : choisir une mise en page prédéfinie.

## Ajouter un avatar ou une bannière

- **Avatar** : téléversez votre image dans la section correspondante. Le fichier est enregistré côté serveur et référencé dans la signature.
- **Bannière** : si l'option est disponible, ajoutez une image PNG et un lien de redirection. Les invités voient une bannière locale qui n'est pas poussée sur le serveur.

## Exporter ou importer une signature

- **Exporter** : cliquez sur l'option d'export JSON pour sauvegarder votre configuration et la partager.
- **Importer** : chargez un fichier `.json` généré par l'application. Si vous êtes invité, les éléments réservés à l'administration seront ignorés.

## Installer la signature dans votre messagerie

- **Copier/Coller** : utilisez le bouton de copie HTML depuis l'application puis collez dans les préférences de signature de Gmail/Outlook/Apple Mail.
- **Mise à jour Gmail automatique** : si activé, connectez votre compte Google via le bouton dédié ; l'application appliquera la signature directement dans Gmail. Vous pouvez vous déconnecter à tout moment.

## Support

En cas de problème (avatar qui ne s'affiche pas, lien Gmail expiré, bannière absente), contactez votre support interne en précisant l'URL et l'heure de l'incident.
